# Python Zero to Hero

A beginner-friendly Python learning repository covering core syntax, data structures, functions, object-oriented programming, problem solving, and interview exercises.

## Contents

- `Python_Zero_to_Hero_Complete_Notes.pdf` — complete study notes
- `basics/` — variables, operators, conditions, and loops
- `data_structures/` — lists, tuples, sets, and dictionaries
- `functions/` — reusable functions and argument patterns
- `oop/` — classes, inheritance, and polymorphism
- `problem_solving/` — number, string, and list challenges
- `exercises/` — interview-style practice questions

## Requirements

- Python 3.10 or newer is recommended.
- No third-party packages are required for the examples in this repository.

## Getting started

1. Install Python from the official Python website: https://www.python.org/downloads/
2. Clone or download this repository.
3. Open a terminal in the repository directory.
4. Run any example, for example:

   ```bash
   python basics/variables.py
   python problem_solving/number_problems.py
   python exercises/interview_questions.py
   ```

   On some Windows installations, use `py` instead of `python`.

## Learning path

1. Start with `basics/`.
2. Practise each collection in `data_structures/`.
3. Learn to break problems into functions.
4. Study the OOP examples.
5. Attempt the problem-solving files without looking at the solutions first.
6. Add your own examples and tests as you learn.

## Suggested practice routine

- Type the code yourself instead of only copying it.
- Predict the output before running a program.
- Change the input values and test edge cases.
- Write down what caused an error and how you fixed it.
- Commit progress to Git regularly.
